# SIKA - Bab 3: Desain Antarmuka dengan CSS3 dan Responsive Web Design

Proyek lanjutan dari Bab 2 (semantic HTML) dengan styling CSS eksternal, Flexbox, Grid, dan media query.

## Struktur

```
sika/
├── index.html
├── mahasiswa.html
├── form-mahasiswa.html
├── assets/
│   ├── css/style.css
│   └── images/mahasiswa.jpg   (placeholder, ganti dengan foto Anda)
└── docs/
    ├── 02-design/css-style-guide.md
    ├── 03-security/ui-security-checklist.md
    └── 04-testing/
```

## Cara Pakai

Buka `index.html` di browser. Uji dengan Developer Tools (F12) > Responsive/Device Toolbar pada lebar 360, 768, dan 1200 px.
